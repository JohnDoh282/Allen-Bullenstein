# Allen Bullenstein

Character art for the Allen Bullenstein Solana meme-token project.

## Assets
- `allen_bullenstein.png` — primary character artwork

## Character concept
Allen is an unemployed, perpetually bullish Solana meme-coin degenerate who burns through every check on rug pulls, lives on Diet Coke, and considers himself a legendary crypto investor despite an endless history of disastrous trades.

Tagline: **UNEMPLOYED. UNDERFUNDED. OVERLEVERAGED. LEGENDARY.**
